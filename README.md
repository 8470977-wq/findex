## 1. Sanity Checks для алгоритмів ранжування
- **Sanity Check 1 (Рідкісний термін вище частотного)**: Термін із меншим `df` (вищим IDF) дає більший приріст до `score`, ніж частий термін.
- **Sanity Check 2 (Насичення частоти / 20-те повторення)**: У BM25 завдяки параметру $k_1 = 1.5$ 20-те повторення того самого слова практично не збільшує релевантність (властивість Term Frequency Saturation).
- **Sanity Check 3 (Нормалізація довжини)**: Короткий документ з 1 входженням терміну отримує вищий балл, ніж дуже довгий документ з 1 входженням терміну (завдяки параметру $b = 0.75$).

## 3. Декоратори @timed та @lru_cache (Cache Hit)

У модулі `ranking.py` реалізовано:
- **`@timed`**: вимірює час виконання методів пошуку за допомогою `functools.wraps`.
- **`@lru_cache`**: кешує результати однакових пошукових запитів.
