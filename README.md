# findex — Пошукова система (Лабораторна 3)

## Особливості реалізації Лабораторної 3
- **Об'єктна модель та ранжування**:
  - Реалізовано модуль `Ranker` для знаходження релевантності документів за двома алгоритмами:
    - **TF-IDF** (Term Frequency — Inverse Document Frequency).
    - **Okapi BM25** (з параметрами $k_1 = 1.5$, $b = 0.75$).
- **Метрики та довжини документів**:
  - Автоматичне врахування середньої довжини документа (`avgdl`) для нормалізації частоти термінів у BM25.
- **CLI Інтерфейс для ранжованого пошуку**:
  - `python -m findex.cli_rank` дозволяє виконувати пошук із виводом Top-N релевантних документів, часу виконання та використання пам'яті.

*Примітка:* Алгоритм **Okapi BM25** показує кращі результати на довгих документах завдяки штрафуванню за надмірну довжину через параметр $b$ та насиченню частоти терміну через $k_1$.
