# findex — Лабораторна робота 1: Ітератори, генератори та корпус

## Опис
Проєкт реалізує потоковий аналіз та токенізацію текстового корпусу з порівнянням лінивого (Lazy) та жадібного (Greedy) підходів за допомогою `tracemalloc`.

## Результати порівняння (Lazy vs Greedy)

| Метрика | Lazy (Генератори) | Greedy (Списки) |
| :--- | :--- | :--- |
| **Час виконання (с)** | 0.0020 s | 0.0009 s |
| **Пікова пам'ять (MB)** | 0.01 MB | 0.01 MB |

> *Примітка:* Заміри зроблено на тестовому корпусі. Для великих корпусів (~50 МБ) Lazy-підхід зберігає низьке використання пам'яті, тоді як Greedy-підхід завантажує всі токени та документи в пам'ять одночасно.
